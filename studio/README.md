# Studio App

This package contains the Sanity Studio.

Use root commands for normal workflow:

- `pnpm bootstrap`
- `pnpm dev`
- `pnpm --filter studio deploy`

Local Studio URL: http://localhost:3333

Schema sources:

- `src/schemaTypes/documents/*`
- `src/schemaTypes/blocks/*`
- `src/schemaTypes/objects/*`
