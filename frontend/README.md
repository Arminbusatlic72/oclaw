# Frontend App

This package contains the Next.js application.

Use root commands for day-to-day work:

- `pnpm bootstrap`
- `pnpm dev`
- `pnpm validate`

Local app URL: http://localhost:3000

Main block rendering entry points:

- `app/components/PageBuilder.tsx`
- `app/components/BlockRenderer.tsx`
- `app/components/blocks/*`

Sanity query/type sources:

- `sanity/lib/queries.ts`
- `sanity.types.ts`
